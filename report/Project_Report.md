# Real World Data Project

## Dataset
Apple Stock Market Dataset (AAPL)

## Objective
Analyze Apple stock prices and trading volume.

## Analysis Performed
- Dataset inspection
- Statistical summary
- Missing value check
- Closing price analysis
- Trading volume analysis

## Visualizations
1. Apple Stock Closing Price
2. Apple Trading Volume

## Findings
- Stock prices fluctuate over time.
- Trading volume varies significantly.
- No major missing values were found.

## Conclusion
The project demonstrates real-world data analysis using financial market data and basic visualization techniques.
